- Basic Github Workflow:
1. cd folder location
2. git init
3. git branch -M main
4. git add <filename>       (master -> main)
5. git commit -m "Message"
6. git remote add origin git@github.com:Advait550/RepoName.git
6. git remote -v 
8. git push -u origin main

Above steps are to be carried carried out while working on a local folder with git for the first time.
Afterwards, following sequence is enough.
1. git status
2. git add <filename>
3. git commit -m "message"
4. git push
